Este es el primer post de mi blog. Lo creo con dos objetivos: **ordenar lo que voy aprendiendo** y **compartirlo** por si le sirve a alguien más.

## De qué voy a escribir

- Cosas que aprendo programando y resolviendo problemas reales.
- Notas técnicas que me gustaría haber encontrado yo cuando las necesitaba.
- Proyectos en los que trabajo y las decisiones detrás de ellos.

## Cómo está hecho este sitio

Este blog está construido con [Astro](https://astro.build) y desplegado gratis en GitHub Pages. Cada vez que subo un cambio, se publica solo mediante GitHub Actions.

Para escribir un post nuevo solo creo un archivo Markdown en `src/content/blog/` y listo.

Nos leemos pronto.
