This is the first post on my blog. I am creating it with two goals: **to organize what I learn** and **to share it** in case it helps someone else.

## What I will write about

- Things I learn while programming and solving real problems.
- Technical notes I wish I had found when I needed them.
- Projects I work on and the decisions behind them.

## How this site is built

This blog is built with [Astro](https://astro.build) and deployed for free on GitHub Pages. Every time I push a change, it is published automatically with GitHub Actions.

To write a new post, I only need to create a Markdown file in `src/content/blog/`.

See you soon.
